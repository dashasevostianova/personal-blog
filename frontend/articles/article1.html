Evolutionary programming

GOAL

To find string such that its length is small, but all symbols are vowels

ENVIRONMENT

Strings and some letters, both vowels and consonants. We limit its number to 100.

fitness score:
Fitness score varies from almost zero to to 100 (if string contains only one vowel). The formula for fitness score is: 50*(1/len) + 50*(vowels/len).

MECHANICS

  • Index of string to which we will add a new letter is selected rsndomly. Letter added to an end.
  • The first letter is removed from every string.
  • If fitness score is less than maximum one more than in 3 times - death.
    If fitness score is less than maximum one more than in 1.5 times - no reproduction.
    Else - reproduction.
  • While reproducting, new string with crossover + applying mutation.
